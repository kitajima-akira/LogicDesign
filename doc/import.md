# LogicDesignでの処理対象ファイル決定の仕組み

LogicDesignでは、Quartusなどのツールを用いる場合、次のように必要なファイルを決め、処理できるように自動で下準備します。

1. LogicDesign直下の設計ファイル(拡張子.sv, .v, .vhdのファイル)
2. 処理対象のファイルのあるディレクトリ(フォルダ)の設計ファイル

上記以外のフォルダにあるファイルは処理対象とはなりません。
このため、エラーを含む記述や書きかけで完成していないファイルは、そのままではエラーで処理が進められないことになりますが、別のフォルダに移動させることにより、処理対象から除外できます。

## import.txt
import.txtファイルにより別のフォルダにあるファイルを処理対象ファイルとして指定することができます。

import.txtは1と2のどちらのフォルダにも置くことができます。
ただし、指定されたファイルが重複している場合、処理系によりエラーが発生する場合があります。

### import.txtの書き方
import.txtには、1行ごとにファイルを指定します。
ファイルの相対パスまたは絶対パスを記述します。通常は相対パスを記述してください。
1行に指定できるのは一つのファイルだけです。フォルダ名やワイルドカードなどは指定できません。
行の先頭の文字が「#」の場合、その行は無視されます。
